# VPS Operations Manual

*Everything you need to run the bot on a Hostinger VPS.*

---

## 1. Access

**SSH:**
```bash
ssh <user>@<vps-host>   # keep the real host out of the repo
```

**Browser terminal (fallback):**
hPanel → VPS → Browser Terminal

**If SSH times out:**
- Check VPN (VPN drops kill TCP connections to port 22)
- Run `wsl --shutdown` from PowerShell, reopen WSL
- Use browser terminal as fallback
- Last resort: reboot from hPanel

## 3. Systemd commands

**Check timer status:**
```bash
systemctl list-timers | grep hlbot
```

**Check service status:**
```bash
systemctl status hlbot.service
```

**Run a cycle manually (as hlbot):**
```bash
sudo -u hlbot bash -c "cd /home/hlbot/hyperliquid-stat-arb-bot && source .venv/bin/activate && HLBOT_RUNTIME_DIR=/home/hlbot/hlbot-runtime/live python scripts/run_cycle.py --config config/phase3-live.yaml"
```

Live mode refuses to run without `HLBOT_RUNTIME_DIR`, and a lock file in the
runtime directory stops a manual run from overlapping a timer run.

**Shadow (dry-run) cycle with live settings:**
```bash
HLBOT_RUNTIME_DIR=/home/hlbot/hlbot-runtime/shadow python scripts/run_cycle.py --config config/phase3-live-shadow.yaml
```

**View live logs:**
```bash
journalctl -u hlbot.service -f
```

**View recent logs:**
```bash
journalctl -u hlbot.service --since "24 hours ago" | tail -30
```

**Restart timer (after config change):**
```bash
sudo systemctl restart hlbot.timer
```

## 4. Common operations

### Check health
```bash
cd /home/hlbot/hyperliquid-stat-arb-bot
sudo -u hlbot bash -c "source .venv/bin/activate && python scripts/check_dry_run.py"
```

### Full statistical analysis
```bash
sudo -u hlbot bash -c "cd /home/hlbot/hyperliquid-stat-arb-bot && source .venv/bin/activate && python -c \"
import pandas as pd
t = pd.read_csv('reports/trades.csv')
print(f'Trades: {len(t)}')
print(f'Win rate: {(t.pnl_usd > 0).mean():.1%}')
print(f'Total PnL: \\\${t.pnl_usd.sum():+.2f}')
print(t.exit_reason.value_counts())
\""
```

### Update the code (git workflow)
```bash
cd /home/hlbot/hyperliquid-stat-arb-bot
git pull origin main
chown -R hlbot:hlbot .
```

### Fix ownership (after root operations)
```bash
chown -R hlbot:hlbot /home/hlbot/hyperliquid-stat-arb-bot
```

### Emergency stop
```bash
sudo systemctl stop hlbot.timer
```
This stops the timer. The service still runs one cycle if manually triggered, but no automatic cycles.

To restart:
```bash
sudo systemctl start hlbot.timer
```

## 5. Troubleshooting

| Symptom | Likely cause | Fix |
|---|---|---|
| `dubious ownership` error | Files owned by root, running as hlbot | `chown -R hlbot:hlbot ...` |
| Cycle never runs | Timer not active | `sudo systemctl status hlbot.timer` |
| Cycle crashes | Bug in code | Check `logs/cycle_*.log` |
| SSH timeout | VPN drop | Reboot WSL, use browser terminal |
| Disk full | Logs grown huge | `sudo journalctl --vacuum-size=100M` |
| Python import error | Venv not activated | `source .venv/bin/activate` |

## 6. Backups

**What to back up:**
- `state/positions.json` — open positions
- `reports/trades.csv` — trade history
- `reports/signals.csv` — signal history
- `.env` — API keys (encrypted!)

**What NOT to back up:**
- `.venv/` — regenerated by pip
- `logs/` — ephemeral
- `__pycache__/` — regenerated

**Simple backup script:**
```bash
tar -czf ~/backup_$(date +%Y%m%d).tar.gz \
    /home/hlbot/hyperliquid-stat-arb-bot/state \
    /home/hlbot/hyperliquid-stat-arb-bot/reports \
    /home/hlbot/hyperliquid-stat-arb-bot/config \
    /home/hlbot/hyperliquid-stat-arb-bot/.env
```

Run weekly. Copy off-server via scp.

## 7. Security hygiene

- **Never commit `.env`.** Verify with `git status` before every commit.
- **Never share your API key.** If compromised, revoke immediately on Hyperliquid.
- **Keep the OS updated.** `sudo apt update && sudo apt upgrade` weekly.
- **Restrict UFW to SSH.** `sudo ufw status` should show only 22/tcp ALLOW.
- **Rotate API keys quarterly.** Generate new, update `.env`, revoke old.
- **Read `journalctl` weekly.** Look for repeated auth failures.
