# Experiments (not part of the live runtime)

Scratch and research scripts live here. They are not imported by
`main.py` / the phase3 scheduler.

On the live host, untracked studies such as `directional_perp_v2..v4.py`
and `leverage_study.py` should be moved into this folder (or deleted)
so the top-level `scripts/` tree stays operational tools only.
